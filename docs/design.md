## 2. Цвета

| Роль | HEX | Где используется |
|---|---|---|
| Primary | `#F28C28` | главные кнопки («В корзину», «Смотреть каталог»), акценты, цена |
| Secondary | `#FBBF24` | бейджи, скидки, подсветка, второстепенные акценты |
| Tertiary | `#0D9488` | иконки категорий, статус «Доставлен / Оплачен», ссылки |
| Neutral | `#1F2937` | заголовки, тёмные кнопки, футер |
| Фон страницы | `#FFFFFF` / светло-голубовато-серый | основной фон и фон карточек |
| Основной текст | тёмно-коричневый (из палитры Stitch) | абзацы, описания |
| Ошибка / удалить | красный | кнопка «Удалить», ошибки форм |

Правила:
- Главный цвет только для кнопок и ключевых акцентов, фон остаётся светлым.
- Текст всегда тёмный на светлом, без светло-серого на белом.
- Для статусов заказа: «Новый» — Secondary, «В пути» — Primary, «Доставлен» — Tertiary, «Отменён» — красный.

> Проверьте точные HEX в экспорте Stitch (Export → DESIGN.md) и поправьте таблицу, если значения отличаются.

## 4. Кнопки

| Вид | Применение |
|---|---|
| **Primary** | главное действие на странице: «В корзину», «Оформить заказ», «Смотреть каталог» |
| **Secondary** | второстепенное: «Подробнее», «Назад» |
| **Inverted** (тёмная, Neutral) | на светлых блоках, «Войти» |
| **Outlined** | нейтральное действие: «Фильтры», «Сбросить» |
| **Icon-кнопки** (круглые) | редактировать, поделиться, тег, удалить (красная) |

- Скругление: 8–12 px, высота 40–48 px.
- На каждой странице одна главная Primary-кнопка.

## 5. Карточки

**Карточка товара:** фото сверху, бейдж («Хит», скидка) в углу фото, название, короткое описание, цена (Primary, жирная), старая цена зачёркнута при скидке, кнопка «В корзину» на всю ширину.
- Фон белый, скругление 12–16 px, лёгкая тень, отступ внутри 16 px.
- Если остаток 0: кнопка неактивна, надпись «Нет в наличии».

**Карточка категории:** иконка в Tertiary, название, число товаров.

**Блок доставки и оплаты:** иконка, заголовок, 1–2 строки текста.

## 6. Поля ввода и навигация

- **Поиск и поля форм:** светлый фон, рамка 1 px, скругление 8–12 px, иконка лупы слева в поиске; при фокусе рамка Primary.
- **Метки полей** над полем, ошибки красным под полем.
- **Нижняя / верхняя навигация:** пилюля со значками (главная, поиск, профиль), активный пункт в круге Primary.

## 7. Отступы и сетка

- Базовая единица: 8 px (отступы 8, 16, 24, 32, 48).
- Контейнер: максимум 1200 px, по центру.
- Каталог: сетка 4 колонки на десктопе, 2 на планшете, 1 на телефоне.
- Расстояние между секциями: 64–80 px.

## 8. Общие элементы на всех страницах

- **Шапка:** логотип TVORIBOX, меню (Каталог, Доставка, Контакты), иконка корзины, кнопка «Войти» / иконка профиля. Переключателя языков нет.
- **Подвал:** логотип, разделы, контакты (телефон, email, адрес), копирайт.
- Весь текст на русском. Без lorem ipsum.

## 10. Чего нет в MVP (не добавлять в дизайн)

- «Избранное»
- отзывы и рейтинг
- чат с продавцом
- несколько продавцов

## 11. Инструкция для ИИ-агента (фронтенд)

- Собирать интерфейс на React (Vite), цвета и размеры вынести в CSS-переменные из разделов 2–3 и 7.
- Компоненты: `Header`, `Footer`, `Button` (варианты primary / secondary / inverted / outlined), `ProductCard`, `CategoryCard`, `Input`, `StatusBadge`.
- Не копировать HTML из Stitch, ориентироваться на скриншоты в `docs/screens/` и на этот файл.
